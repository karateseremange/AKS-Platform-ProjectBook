- aucune fonction `doPost` ni autre point d’entrée actif.

## 5. Registre anti-rejeu

Le registre implémenté sépare les empreintes de `requestId` et de nonce. Il utilise des ports de stockage, verrou, horloge et cryptographie injectés.

L’adaptateur Apps Script prévu pour une phase future combine :

- `PropertiesService.getScriptProperties()` ;
- `LockService.getScriptLock()` ;
- empreintes SHA-256 ;
- écriture groupée des deux clés ;
- relecture obligatoire après écriture ;
- purge bornée des enregistrements expirés ;
- libération du verrou dans un bloc `finally`.

Cet adaptateur refuse de s’instancier si `enabled` n’est pas strictement vrai ou si l’environnement n’est pas exactement `RECETTE`. Il n’est appelé par aucun point d’entrée du lot.
