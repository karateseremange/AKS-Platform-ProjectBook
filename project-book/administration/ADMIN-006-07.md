## 4. Résultat fonctionnel

Le lot C fournit :

- un contrôle serveur explicite de `LOG_READ` avant configuration ou transport ;
- une identité issue exclusivement du contexte serveur ;
- la construction d’une requête `LOG_READ_RECENT_V1` via `AKS-PRIVATE/1` ;
- la validation cryptographique et la corrélation de la réponse ;
- des identifiants et un nonce renouvelés à chaque tentative ;
- un transport injectable mais inactif par défaut ;
- les états fermés `AVAILABLE`, `EMPTY`, `DISABLED` et `UNAVAILABLE` ;
- un modèle Journaux isolé du reste du portail ;
- un affichage dégradé avec action Réessayer ;
- le maintien de l’accès à Administration lorsque Journaux est indisponible.

Paramétrage et Journaux restent deux destinations et deux autorisations indépendantes. Le lot C ne raccorde aucune capacité `CONFIG_*`.
