# Guides opérationnels AKS Platform

Ces guides décrivent les modules validés d'AKS Platform. Chaque document précise
son public et son périmètre.

## Publics concernés

| Document | Public | Objectif |
|---|---|---|
| [Guide d'installation et d'administration](administration/GUIDE-INSTALLATION-ADMINISTRATION.md) | Administrateur technique | Installer, configurer, sécuriser, mettre à jour et dépanner la plateforme |
| [Guide utilisateur du club](utilisateur/GUIDE-UTILISATEUR-CLUB.md) | Président, secrétaire, gestionnaire autorisé | Créer une campagne et suivre les formalités du questionnaire santé |
| [Guide de saisie des présences](utilisateur/GUIDE-SAISIE-PRESENCES.md) | Professeurs et assistants autorisés | Saisir, enregistrer, reprendre et clôturer les présences d'une séance |
| [Fiche questionnaire mineur](familles/FICHE-QUESTIONNAIRE-MINEUR.md) | Familles et représentants légaux | Comprendre et compléter le questionnaire en ligne |

## Principes communs

- utiliser uniquement un compte personnel autorisé ;
- ne pas diffuser de secret, d'identifiant technique privé ou de donnée
  personnelle dans la documentation ;
- distinguer les données de production des données fictives de recette ;
- vérifier le cours, la saison et la date avant tout enregistrement ;
- signaler les anomalies sans modifier directement les feuilles techniques.

## Confidentialité du questionnaire santé

- les réponses détaillées restent confidentielles ;
- elles ne sont jamais communiquées au club ;
- elles ne sont conservées ni dans Google Sheets, ni dans WordPress ;
- seul le représentant légal reçoit leur récapitulatif par e-mail ;
- le club reçoit uniquement l'identité, la référence et la formalité attendue.

## Versionnement

Les guides suivent les versions validées d'AKS Platform. Toute évolution d'une
interface, d'une règle métier ou d'une procédure doit entraîner une revue du
guide concerné.
