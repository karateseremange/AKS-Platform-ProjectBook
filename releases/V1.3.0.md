# AKS Platform V1.3.0

## Statut

Publiée le 1er août 2026.

La V1.3.0 est publiée sur `main`. Le tag documentaire `v1.3.0` pointe sur le commit `647ae45a501bf14c1f3463fbca480945993bc515`.

## Objectif

La V1.3.0 publie officiellement AKS Calendar, un socle partagé reposant sur Google Calendar et WordPress. Elle fournit un calendrier public pour les licenciés et familles, trois calendriers internes pour l’organisation du club et un circuit simple de proposition puis de validation des événements.

## Périmètre publié

- `AKS - Public` pour les événements destinés aux licenciés, familles et visiteurs ;
- `AKS - Encadrement` pour les professeurs et assistants ;
- `AKS - Administration / Comité` pour les réunions et événements internes ;
- `AKS - Propositions` pour la préparation avant validation ;
- circuit de copie des événements validés vers `AKS - Public` ;
- publication du calendrier public sur WordPress ;
- abonnement direct dans Google Agenda ;
- téléchargement iCal pour les autres applications compatibles ;
- page WordPress protégée donnant accès aux trois calendriers internes ;
- maintien des autorisations Google Agenda comme contrôle d’accès effectif ;
- guide utilisateur et procès-verbaux de recette.

## Validation

- quatre calendriers créés, nommés et configurés ;
- droits internes testés ;
- création, validation, copie et suppression d’un événement temporaire testées ;
- affichage WordPress validé sur ordinateur et mobile ;
- abonnement Google Agenda validé ;
- téléchargement `.ics` validé ;
- accès interne bloqué avant saisie du mot de passe WordPress ;
- demande de connexion Google vérifiée ;
- accès avec un compte autorisé vérifié ;
- menu `Services en ligne` validé sur ordinateur et mobile ;
- données temporaires de recette supprimées ;
- aucun défaut bloquant ou critique connu.

## Compatibilité et continuité

- aucun changement du code Google Apps Script ;
- aucun redéploiement applicatif requis ;
- Questionnaire santé, administration, Analytics et saisie des présences inchangés ;
- sécurité des calendriers internes assurée en dernier ressort par les droits Google Agenda ;
- aucune dépendance envers l’environnement Proxmox personnel ;
- aucune migration de données.

## Limites et suites différées

- pas de synchronisation développée dans AKS Platform ;
- pas de workflow applicatif d’approbation ;
- pas de journalisation interne des opérations Google Calendar ;
- pas de gestion automatisée des droits depuis AKS Platform ;
- mécanismes avancés à réévaluer uniquement si un besoin concret justifie leur coût.
