## Contenu intégré dans la candidate

- administration ACCESS des comptes, rôles et habilitations explicites ;
- migration de Paramétrage, Journaux et Analytics vers les capacités ACCESS ;
- Portail AKS, « Mes accès » et « Comptes et accès » ;
- AUDIT persistant compatible avec des supports RECETTE et PRODUCTION distincts ;
- évolutions cumulatives de Présences depuis V1.2.0 ;
- fondations INSCRIPTIONS-007 à INSCRIPTIONS-010, internes et sans route Web publiée ;
- fuseau Apps Script `Europe/Paris`.

## Validation obtenue

La tête exacte RC5 a été synchronisée dans Apps Script de recette :

- VERSION-001 : **8/8 réussis** ;
- ACCESS administration : **15/15 réussis** ;
- campagne cumulative : **665/665 réussis** ;
- déploiement Web de RECETTE existant conservé en version Apps Script **8** ;
- ouverture de « Comptes et accès » sans dépendance AUDIT prématurée ;
- erreur d’historique minimisée et affichée localement sans détail technique ;
- registre ACCESS et configuration AUDIT restaurés exactement après recette ;
- sauvegardes et identités fictives temporaires supprimées.

Les défauts observés de RC1 à RC4 ont produit des candidates distinctes. RC5 est
la seule candidate courante ; aucune candidate antérieure n’est présentée
comme publiable.

## Inventaire de production obtenu

L’inventaire P3 confirme que la production publique exécute toujours la
version Apps Script 53 du déploiement existant `wgNc37`. Son code applicatif
correspond à `main` au commit `e8fb0fc` ; la différence de
`appsscript.json` porte sur les paramètres Web App conservés dans la version
déployée.

Le HEAD Apps Script n’est pas déployé et correspond à `ed03cc4`, complété par
un lanceur INSCRIPTIONS-010 non versionné. La candidate `b13fc20` n’est
présente ni dans la version 53 ni dans le HEAD de production.

La version 53 et le HEAD ont été sauvegardés séparément et rapprochés de Git
dans deux archives durables vérifiées. L’inventaire n’a exécuté aucune URL et
n’a modifié aucune ressource de production.

L’inventaire et le rapprochement P3 sont clôturés. P4-A à P4-F sont terminés
sur RC5 ; aucun défaut bloquant ou critique connu ne reste ouvert. Le rapport
[ACCESS-002-PRODUCTION-P4-G](../project-book/administration/ACCESS-002-PRODUCTION-P4-G.md)
